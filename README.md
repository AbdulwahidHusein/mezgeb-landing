# Mezgeb AI — Marketing Website

Premium dark enterprise marketing site for Mezgeb AI, an Ethiopian document-intelligence company.

## Stack

- **Next.js** (App Router) + TypeScript + Tailwind CSS v4
- **shadcn/ui** — Button, Card, Accordion, Badge, Input, Label, Textarea, Separator
- **Magic UI** — Border Beam, Shimmer Button, Dot Pattern, Animated Grid, Text Animate, Shine Border, Aurora Text
- **Motion** for React
- **Geist** + **Noto Sans Ethiopic**

## Design direction

Dark forest / electric emerald enterprise aesthetic inspired by premium SaaS marketing templates (glass surfaces, soft emerald glow, oversized watermark type, floating product orb) — adapted to Mezgeb brand colors, not purple stock AI themes.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Notes

The pilot contact form validates in the browser only. Submissions are not delivered to a backend.
